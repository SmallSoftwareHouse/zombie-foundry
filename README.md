# Games Server Manager

Tool per la gestione di server dedicati Source Engine (Left 4 Dead 2, ...) su Windows.
Crea, configura, avvia e monitora i tuoi server da un'unica interfaccia.

> ⚠️ **Versione beta** — in test con i beta tester. Segnala problemi e suggerimenti.

## Download
Scarica l'ultima versione dalla pagina **[Releases](../../releases/latest)**:
- **`gsm.exe`** — eseguibile unico, tutto incluso (nessuna installazione).

## Come si usa
1. Metti `gsm.exe` in una **cartella tua** (Desktop, Documenti, una cartella dedicata) — **non** in `C:\Program Files` (deve poter scrivere).
2. Avvia `gsm.exe`.
3. Al primo avvio crea da solo le sue cartelle (config, servers, logs, downloads) accanto a sé. È **portable**: tutto resta nella sua cartella.

> 🛡️ L'eseguibile non è firmato: Windows potrebbe mostrare "App non riconosciuta" → **Ulteriori informazioni** → **Esegui comunque**. Normale per una build beta.

## Requisiti
- Windows 10/11 (64-bit)
- Connessione a Internet (download dei server via SteamCMD e controllo aggiornamenti)

## Aggiornamenti
Il tool controlla gli aggiornamenti automaticamente e ti indica quando scaricare la nuova versione da questa pagina.
